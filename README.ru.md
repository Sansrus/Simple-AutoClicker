# Simple AutoClicker

Настраиваемый клиентский автокликер для Minecraft Fabric. Поддерживает выполнение различных игровых действий с задержкой, по таймеру и в спам-режиме.

**[English version](README.md)**

---

## Возможности

- **Несколько независимых профилей** — у каждого автоклика своё название, действие, тайминги и переключатели
- **Гибкие тайминги** — отдельные интервал (пауза) и время использования (продолжительность удержания) в тиках
- **Спам-режим** — повтор каждый тик без задержки (`interval = 0`)
- **Альтернативные действия** — привязка автоклика к любой ванильной клавише (прыжок, инвентарь, F-клавиши и т.д.) ⚠ работает не со всеми действиями
- **Графический интерфейс** — открывается по кнопке (по умолчанию F4) или через ModMenu; вкл/выкл через назначенную клавишу
- **Оповещение над хотбаром** — показывает, когда автокликер включён/выключен

## Доступные действия

| Действие                                 | Описание                                                       |
|------------------------------------------|----------------------------------------------------------------|
| Движение вперёд / назад / влево / вправо | Удержание клавиш движения                                      |
| Бег                                      | Удержание бега                                                 |
| Прыжок                                   | Прыжок (безопасно: земля, вода, лава, лестница, верховая езда) |
| Красться                                 | Удержание приседания                                           |
| Использовать                             | ПКМ: предметы (еда, лук, арбалет и т.д.), блоки, сущности      |
| Атаковать                                | ЛКМ: сущность или блок                                         |
| Выбросить                                | Выкинуть предмет из руки                                       |
| Выбрать блок                             | Взять блок/сущность на панель (средняя кнопка)                 |
| Заменить предмет                         | Переложить предмет во вторую руку и обратно                    |
| Сменить перспективу                      | Циклическое переключение камеры                                |
| Скриншот                                 | Сделать скриншот                                               |
| Слоты 1–9                                | Выбор слота хотбара                                            |
| Альтернативное                           | Запуск любой ванильной клавиши через выбор в меню              |

## Как использовать

1. Нажмите клавишу(настроить в настройках управления) для открытия GUI, или откройте через ModMenu
2. Добавьте профиль автоклика, выберите действие, настройте тайминги
3. Нажмите назначенную клавишу вкл/выкл мода (по умолчанию не назначена — установите в ванильных настройках управления) для включения/отключения автокликера

### Советы

- **Для блоков (Use):** установите `useDuration > 1` для непрерывной установки; `useDuration = 1` ставит ровно один блок за цикл
- **Для предметов (Use):** мод автоматически удерживает ПКМ для расходуемых предметов (еда, лук); отпускание происходит через `useDuration` тиков
- **Действие «Альтернативное»:** нажмите кнопку «Выбрать» для открытия меню выбора клавиши; все ванильные привязки сгруппированы по категориям с поиском. ⚠ Некоторые действия могут работать некорректно!
- **Глобальное включение:** назначьте клавишу в управлении (Настройки → Управление → Simple AutoClicker → «Переключить»)

## Модель времени

Мод использует **клиентские тики** (20 тиков = 1 секунда при 20 TPS).

- **Интервал (ждать):** пауза между циклами действия в тиках
- **Время использования:** сколько тиков действие активно за один цикл
- **Спам-режим:** interval = 0 — действие срабатывает каждый тик без остановки

## Требования

- Minecraft 26.1 (1.21.5)
- Fabric Loader ≥0.16.0
- Fabric API (рекомендуется)
